    Follow thread links from search results and transcripts to reopen saved conversations and nested agents, press Tab to complete slash-command arguments, and jump between task groups in the agent command center. App-server clients can pick Amazon Bedrock Runtime at setup, and codex exec resume now restores saved sandbox permissions and workspace roots.

  • 20 Nov 2026OpenAI Agents SDK 1.0 alpha: Codex as a model provider

    The first preview of Agents SDK v1.0.0 for Python adds Codex as an opt-in model provider (CodexProvider), embedding Codex Core so agents can run on Codex with SDK tools, handoffs and approvals. The alpha wheels are available only through GitHub Releases.

    Source
  • 20 Nov 2026OpenAI Codex CLI 0.171: GPT-6.2 Sol by default and TUI workspace

    Adds GPT-6.2 Sol and Astra to the model catalog with Sol as the default selection, turns on the TUI workspace by default (searchable document and image previews and subagent transcripts beside the chat), adds undo and redo in the prompt composer, and codex exec --remote for sessions on an existing app server.

    Source
  • 16 Nov 2026TeamCity AI Agents plugin: Codex and Claude Code in CI (experimental)

    JetBrains' experimental plugin installs Codex or Claude Code on a TeamCity build agent, hands over provider credentials only for the build, and records token counts and the agent's full trajectory as HTML/JSON. Connects to OpenAI, Anthropic, OpenRouter, LiteLLM or JetBrains Air.

    Source
  • 13 Nov 2026OpenAI Codex CLI 0.169: side-chat tabs

    The opt-in terminal workspace now supports multiple side-chat tabs you can reopen after a restart, and you can search older tasks in the agent command center. Codex exec now keeps project config and MCP servers off in untrusted folders unless you pass --trust.

    Source
  • 6 Nov 2026OpenAI Codex CLI 0.167: agent command center

    OpenAI's Codex CLI rust-v0.167.0 adds codex agents --no-daemon for an agent command center with unread markers, lets you switch backends from the session picker without losing drafts, and adds local image previews plus a Google Cloud Vertex AI setup path.

    Source
  • 29 Oct 2026OpenAI Codex CLI 0.166

    Codex CLI 0.166.0 adds keyboard-driven transcript selection with search, codex queue --resume for unloaded threads, codex doctor --network-only diagnostics, clearer safety-block explanations, and GPT-6.1 Terra in the bundled, Vertex AI and Amazon Bedrock catalogs.
