  • 3 Nov 2026Vercel Security Review (public beta)

    Vercel Security Review is in public beta for Pro and Enterprise teams. Once enabled, every push to a connected GitHub repo is reviewed for vulnerabilities, with findings (summary, suggested fix and AI-rated severity) in a Vulnerabilities dashboard, a GitHub check and PR comments. Fix with Vercel Agent opens a PR, or pull findings into your own coding agent with vercel security vulnerabilities. Reviews are free until 10 November 2026, then billed at the Vercel Agent rate.

    Source
  • 28 Oct 2026Vercel Labs agent-desktop 1.0: computer use for any coding agent

    agent-desktop is a free, open-source (Apache 2.0) Rust CLI that lets agents like Claude Code or Codex operate desktop apps on macOS, Windows and Linux by reading the OS accessibility tree instead of screenshots, returning JSON element references and retry-safe error codes. Version 1.0 (adding Linux) shipped 28 Oct, with 1.0.2 on 30 Oct; it installs via npm.

    Source
  • 22 Oct 2026Vercel: deploy without an account

    Run vercel deploy --temporary to get a live tmp.now URL for a project or a single file without signing in. Temporary deployments expire after one hour unless you claim the project via the link in the CLI output.

    Source
  • 20 Oct 2026Vercel WebSockets in Functions (GA)

    WebSocket support in Vercel Functions is generally available, for AI chat, streaming and realtime multiplayer apps, at normal Function pricing (CPU billed only while processing messages).
