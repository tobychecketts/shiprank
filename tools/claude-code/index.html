Recent releases

This week →
  • 13 Nov 2026Claude Code 2.1.325: sandboxed Bash now asks permission by default

    Claude Code 2.1.325 changes sandboxed Bash commands to follow the normal permission flow by default; set sandbox.autoAllowBashIfSandboxed: true to keep running them without prompts. It also fixes a security issue in decoding zstd-compressed responses, and adds prompt suggestions and a Console sign-in that creates no API key in VS Code.

    Source
  • 12 Nov 2026Claude Code 2.1.323: Code Mode (experimental)

    Claude Code 2.1.323 adds Code Mode, an experimental opt-in in which Claude writes JavaScript to call its tools rather than invoking them one at a time. Organisations can turn it off. The release also lets plugins declare a supported Claude Code version range, and adds a menu when a model needs usage credits that are off or used up.

    Source
  • 9 Nov 2026Claude Fable 5.2

    Anthropic's newest Fable model, now the default Fable model in Claude Code (2.1.321) and generally available in GitHub Copilot for Pro+, Max, Business and Enterprise users. 1M context; API price $8/$40 per 1M input/output tokens, down from $10/$50 on Fable 5.1. Also on Vercel AI Gateway.

    Source
  • 9 Nov 2026Codenotary AgentMon Live (open source)

    Free Apache-2.0 plugin for Claude Code (2.1.308+) with a live dashboard of agent and subagent activity, token and cost visibility, and a 'Done Gate' that checks for failed tests or unfinished tasks before the agent says it's done.

    Source
  • 6 Nov 2026Claude Code 2.1.319: background MCP tasks + deny-instead-of-prompting

    Anthropic's Claude Code 2.1.319 backgrounds MCP tool calls that run as tasks, adds permissions.denyInsteadOfPrompting so a blocked tool call fails closed instead of waiting, and ships /claude-api latency-optimize plus CLAUDE_CODE_DISABLE_FEATURE_FLAGS. It also hardens auto mode behind LLM gateways and fixes sandbox-escape and Bash permission-bypass bugs.

    Source
  • 4 Nov 2026Claude Code 2.1.318: cloud sessions without a repo + sign-in expiry warnings

    Anthropic's Claude Code 2.1.318 lets a cloud session on an Anthropic-hosted environment start with no repository picked, shows when a stored claude.ai sign-in ends (in claude auth status and claude -p JSON, plus a warning 10 days before), and adds an effort option for quick side jobs. It also fixes lost --continue history, macOS stalls with many Bash commands, and config and login corruption on shared network home directories.

    Source
  • 31 Oct 2026Claude Code 2.1.316: subagent effort control; Opus 4.8 fast mode deprecated

    Claude Code added CLAUDE_CODE_SUBAGENT_EFFORT to set the effort level subagents run at, a CLAUDE_CODE_DISABLE_ULTRATHINK switch, and pooled group budgets in the Claude apps gateway. Fast mode for Opus 4.8 is deprecated and will be removed on 30 Nov 2026 (requests will error, not fall back); Anthropic says to move to Opus 5.5.

    Source
  • 30 Oct 2026Claude Code: block writes outside working directories + idle compaction

    Claude Code added a permissions.blockWritesOutsideWorkingDirectories setting so Write, Edit and NotebookEdit refuse paths outside your working directories in every permission mode, plus idle compaction in VS Code and Claude Desktop's Code tab that summarises long (200K+ token) idle conversations before your next message.

    Source
  • 15 Oct 2026Claude Code Review (GA)

    Multi-agent review of GitHub pull requests is out of research preview for Claude Team and Enterprise, with reviews ~3x faster (6-10 min) and Quick, Standard or Deep levels per repo.

    Source
