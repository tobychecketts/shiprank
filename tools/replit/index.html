Recent releases

This week →
  • 13 Nov 2026Replit Performance Agent

    Replit's Performance Agent looks for potential slowdowns in your code and logs. Open Monitoring and choose Run scan with Agent, then review and test the fixes before publishing. It needs a paid plan and edit access, and works before you publish. The same update lets admins share projects with individual Viewers.

    Source
  • 12 Nov 2026Replit Agent can buy supplies and run Google Ads

    Replit Agent can now buy supplies for your business and help you run Google Ads, without leaving Replit. Purchases use Link (by Stripe) and Visa: Agent prepares the checkout and waits for you to approve the total before anything is charged. Agentic Commerce is for Core and Pro users, starting in the US and limited to one-time purchases. For ads, Agent can draft copy, images and a budget across Google Search, YouTube, Display and Discover, and you approve before it launches.

    Source
  • 30 Oct 2026Replit Cloud Agents for company codebases (Enterprise) + Agent chat messaging

    Replit Enterprise customers can describe a change in plain language and a Cloud Agent finds the relevant code, makes the change, tests it in the running app and opens a GitHub pull request or GitLab merge request with screenshots and video, working in isolated cloud sandboxes for engineers to review. On Pro and Enterprise, Agent can now send messages to other chats or start new ones, and GPT-6.1 Terra is in the model selector for Agent in Power Mode.

    Source
  • 23 Oct 2026Replit Agent workspace skills + keep apps running past credits

    Replit Agent can now suggest new or improved workspace skills from your chats and projects, which you review and approve before they land. The same update lets eligible top-up customers keep published apps running when credits run out, up to an overage limit, and adds Stripe Atlas on Replit.

    Source
  • 22 Oct 2026Replit Monitoring Agent

    An autonomous on-call agent for apps published on Replit: it reads production logs and metrics, investigates alerts, validates a fix and can auto-publish it, then emails you a summary.

    Source
