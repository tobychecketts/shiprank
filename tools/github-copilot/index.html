Recent releases

This week →
  • 10 Nov 2026Gemini 4 Carbon in GitHub Copilot (GA)

    Google's Gemini 4 Carbon, aimed at complex coding, agentic work and secure code generation, is generally available in GitHub Copilot for Pro+, Max, Business and Enterprise users, billed at provider list pricing. Pick it in VS Code, Visual Studio, Copilot CLI, the coding agent, JetBrains, Xcode and more; rollout is gradual.

    Source
  • 10 Nov 2026Copilot in Visual Studio gets a new engine

    Visual Studio 2026 version 18.12 runs Copilot Chat on the Microsoft Copilot SDK, the same engine as Copilot CLI, the Copilot app and VS Code. You can steer it mid-task, see each step's results and per-request cost, watch subagents live and point it at folders outside your solution. On by default.

    Source
  • 9 Nov 2026Claude Fable 5.2

    Anthropic's newest Fable model, now the default Fable model in Claude Code (2.1.321) and generally available in GitHub Copilot for Pro+, Max, Business and Enterprise users. 1M context; API price $8/$40 per 1M input/output tokens, down from $10/$50 on Fable 5.1. Also on Vercel AI Gateway.

    Source
  • 6 Nov 2026@GitHub in Slack and Teams (GA)

    Mention @GitHub in Slack or Teams to investigate bugs, create issues, implement changes and open pull requests from a conversation. Adds Canvas in Teams for reviewing plans, diffs and previews, plus automatic repo detection.

    Source
  • 4 Nov 2026GitHub Copilot in Xcode's coding assistant (public preview)

    GitHub Copilot is now available inside Xcode's built-in coding assistant as a public preview starting with Xcode 27.3 beta on macOS Tahoe 26.6+. The existing Copilot for Xcode extension remains a separate option; all Copilot plans are supported.

    Source
  • 3 Nov 2026GitHub Copilot in JetBrains Air

    GitHub Copilot is now available as an agent in JetBrains Air through the Agent Client Protocol. Pick Copilot in Air's agent picker to delegate coding tasks on your existing Copilot subscription, track several agent sessions in parallel and review changes next to your code. Cloud tasks run in isolated containers through Air Teams and use your Copilot plan rather than JetBrains AI credits.

    Source
  • 28 Oct 2026GitHub Copilot code review Max (public preview)

    Copilot code review gained a Max tier in public preview: several independent review agents using models from different providers review a pull request, then an aggregation agent reconciles their findings into one review. It's meant for high-risk changes and takes longer and uses more AI credits than Lite or Balanced.

    Source
  • 28 Oct 2026GitHub Copilot app: Projects and computer use (preview)

    Copilot Projects (public preview) give Copilot an ongoing goal that can span several repositories or none, running as many agents as needed and returning pull requests for review, with project automations for repeat tasks. Computer use, in public preview on macOS and Windows, lets Copilot click and type in desktop apps after asking your approval.

    Source
  • 28 Oct 2026GitHub Copilot Fusion (GA)

    Pick Copilot Fusion in the model picker and Copilot routes and orchestrates models for each task, with Standard, High and Max effort levels. GitHub says Fusion Max scored within two points of Claude Code with Opus 5.5 Max on the Artificial Analysis Coding Agent Index at about half the cost. On all Copilot plans in VS Code, the Copilot app, Copilot CLI and JetBrains.

    Source
  • 26 Oct 2026GitHub Copilot assisted permissions (GA)

    When Copilot asks to run a command, touch a path or open a URL, a model evaluates the request: clearly safe ones proceed automatically, the rest still need your approval. Generally available in Copilot CLI (/permissions), the Copilot app and VS Code, with enterprise controls.

    Source
  • 26 Oct 2026GPT-6.1 Terra in GitHub Copilot

    OpenAI's newest model is generally available in Copilot for everyday agentic coding and terminal work at a lower cost than GPT-6.1 Sol. Available on Pro, Pro+, Max, Business and Enterprise across VS Code, Copilot CLI, cloud agent, JetBrains, Xcode and more; billed at provider list pricing.

    Source
  • 23 Oct 2026GitHub app for Microsoft Teams with Copilot

    The new consolidated GitHub app in Teams brings notifications and Copilot together: @mention GitHub on an issue notification and Copilot investigates, fixes the bug and opens a pull request. The legacy app retires on 16 November.

    Source
