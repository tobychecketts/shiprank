# ShipRank

AI tool rankings for vibe coders and builders: tools ranked by use case, with verified pricing and a feed of new releases.

- `index.html` – static site (plain HTML/JS)
- `tools.json` – all tool, pricing and release data (edit this to update the site)

Run locally: `python3 -m http.server` then open http://localhost:8000

## Build (SEO pages)

`python3 build.py` regenerates from `tools.json`:
- `tools/<slug>/index.html` – one page per tool
- `best/<category-slug>/index.html` – one ranking page per category
- `sitemap.xml` and `robots.txt`

Comparison articles live in `data/compare.json` (rendered to `compare/<slug>/`; add tools not in tools.json under `extraTools`).

Guides live in `data/guides.json` (→ `guides/<slug>/`). Weekly roundups are generated from `releases` in `tools.json` (→ `weekly/` latest + `weekly/<year>-w<NN>/` archive; undated releases are skipped).

`/featured/` (sponsorship, launch pricing in GBP) and `weekly/feed.xml` (RSS of dated releases) are also generated by build.py.

Daily routine: update `tools.json` → run `python3 build.py` → commit and push to `main` (GitHub Pages serves the repo root) → once live, `python3 indexnow.py`.

## IndexNow (Bing, Yandex, etc. – no sign-in)

Key file: `e5f47d70a4c91ed0ebc65a31f5ba958e.txt` at the repo root (served at `https://tobychecketts.github.io/shiprank/e5f47d70a4c91ed0ebc65a31f5ba958e.txt`; keep it). After a push is live on GitHub Pages, run:
- `python3 indexnow.py` – pings URLs of HTML pages changed in the last commit
- `python3 indexnow.py --since <ref>` – pages changed since a commit
- `python3 indexnow.py --all` – every URL in `sitemap.xml`

HTTP 200 or 202 means accepted.

## Visit counting (cookie-free, no account)

Every page includes a tiny script that increments anonymous counters on [Abacus](https://jasoncameron.dev/abacus/) (namespace `shiprank.tobychecketts`): `visits` (all pages) and `section-<home|tools|best|compare|guides|weekly|featured>`. No cookies, no personal data. View totals at `/stats/` (noindex, not in sitemap). Counters expire after 6 months without use.
