Shipped lately

  • 12 Nov 2026Gemini 4 Hydrogen in Cursor

    Google's Gemini 4 Hydrogen, the successor to Gemini 3.8 Flash, is now available in Cursor for everyday agentic coding. Cursor says that at its default effort it scores 54.3% on CursorBench, up from 39.6% for Gemini 3.8 Flash. It supports low, medium, high (default) and xhigh effort. It's a third-party model, so it isn't part of the usage included with Cursor plans.

  • 12 Nov 2026Claude Code 2.1.323: Code Mode (experimental)

    Claude Code 2.1.323 adds Code Mode, an experimental opt-in in which Claude writes JavaScript to call its tools rather than invoking them one at a time. Organisations can turn it off. The release also lets plugins declare a supported Claude Code version range, and adds a menu when a model needs usage credits that are off or used up.

  • 12 Nov 2026Replit Agent can buy supplies and run Google Ads

    Replit Agent can now buy supplies for your business and help you run Google Ads, without leaving Replit. Purchases use Link (by Stripe) and Visa: Agent prepares the checkout and waits for you to approve the total before anything is charged. Agentic Commerce is for Core and Pro users, starting in the US and limited to one-time purchases. For ads, Agent can draft copy, images and a budget across Google Search, YouTube, Display and Discover, and you approve before it launches.

  • 12 Nov 2026Claude Meetings (beta)

    Anthropic is rolling out Claude Meetings in beta on Team and Enterprise plans. You can add Claude to a Google Meet call as a visible participant that takes notes, answers questions, and builds docs, whiteboards and other artifacts during the call. Support for other video platforms is coming later. During the beta, notes and transcripts are free; artifacts Claude makes on the call are free through 10 February 2027.

  • 12 Nov 2026v0: Meta's Astryx design system

    Meta's Astryx design system is now available in v0. You can select it for a project and v0 builds with Astryx's components, patterns and templates in context.

  • 11 Nov 2026Lovable Automations

    Automations let Lovable take care of recurring work, such as a morning check of your published sites, a weekly summary of new signups, or a Friday list of the oldest items in your backlog. Ask for one in Chats and say how often, and Lovable posts what it finds there. Available on Free, Pro and Business plans, and each run is chat usage.

  • 11 Nov 2026Qwen Code 1.0 Preview

    Alibaba's Qwen team released a v1.0.0-preview of Qwen Code that merges the agent capabilities of its Qoder coding tool and the open-source Qwen Code CLI into one agent for understanding, implementing, debugging and testing code. You can sign in with a Qwen or Qoder account, and it ships native installers for macOS, Linux and Windows that don't need a separate Node.js install. Marked as a preview, so interfaces and behaviour may change.

  • 11 Nov 2026Gemini 4 Hydrogen in Devin

    Gemini 4 Hydrogen is now live in Devin Desktop and Devin CLI. On Cognition's FrontierCode 2.0 benchmark, it scores 38.2%, close to GPT-6.1 Sol's 39.0% and Gemini 4 Carbon's 40.0%, at $2.40 per task compared with Carbon's $4.04.
