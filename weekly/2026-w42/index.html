What shipped in week 42

12 releases for people building with AI. We only list something once we've seen it on the company's own page.

Sat 17 Oct

  • Perplexity Computer: REA reverse-engineering skill

    New /reverse-engineer skill lets Computer inspect an existing app without its source and rebuild a working version, using the open-source REA MCP toolkit. Tasks free up to 10,000 credits per user until 31 Oct.

    Source · checked 18 Oct 2026

Fri 16 Oct

  • Cursor: canvases from cloud agents + Environments API (beta)

    Cloud agents can build shareable interactive canvases; Environments API in beta; environments now support up to 300 repos and load 5x faster.

    Source · checked 17 Oct 2026
  • Chainguard Workspaces and Checks (beta)

    Hardened microVM dev environments for developers and coding agents, plus fast in-loop CI checks agents can call via MCP or SDK. 30-day beta trials.

    Source · checked 17 Oct 2026

Thu 15 Oct

  • Vercel Token Pass (early access)

    $30/month for $80 of GLM 5.3 and Kimi K3 credit via AI Gateway, for Pro teams.

    Source · checked 16 Oct 2026
  • Vercel AI SDK 7

    AI SDK becomes a provider-agnostic toolkit for building multi-turn agents, announced at Vercel Ship 2026.

    Source · checked 16 Oct 2026
  • Meta Muse Spark Open

    Coding-optimised open-weight MoE model (816B, 42B active) with 1M-token context.

    Source · checked 16 Oct 2026
  • Lovable: AI models and tools inside your apps

    Apps built in Lovable can now use GPT-Live voice, the latest Claude models, Gemini 4 Argon, Gemini Omni, Lyria, Perplexity, Firecrawl, Parallel and Jev without leaving Lovable.

    Source · checked 18 Oct 2026
  • GitHub agentic autofix for code scanning (GA)

    Agents propose fixes for code scanning alerts.

    Source · checked 16 Oct 2026
  • GitHub AI Scan for PRs (GA)

    AI vulnerability scanning on pull requests, complementing CodeQL.

    Source · checked 16 Oct 2026
  • Claude Code Review (GA)

    Multi-agent review of GitHub pull requests is out of research preview for Claude Team and Enterprise, with reviews ~3x faster (6-10 min) and Quick, Standard or Deep levels per repo.

    Source · checked 18 Oct 2026
  • Bluesky Attie site builder

    "Social vibe coding": describe a poll, quiz, guestbook or game and Attie builds a shareable page on attie.site that Bluesky followers can sign in to and use.

    Source · checked 18 Oct 2026
  • Band for Developers

    Desktop app and CLI for managing a team of coding agents at once: projects, ownership, blockers, questions and progress in one view.

    Source · checked 17 Oct 2026
