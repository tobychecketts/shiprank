What shipped this week

New releases from the AI tools builders actually use, newest first. Week 46, 2026. We only list something once we've seen it on the company's own page.

Follow along in your reader with the RSS feed. An email version is on the way.

Mon 9 Nov

  • Claude Fable 5.2

    Anthropic's newest Fable model, now the default Fable model in Claude Code (2.1.321) and generally available in GitHub Copilot for Pro+, Max, Business and Enterprise users. 1M context; API price $8/$40 per 1M input/output tokens, down from $10/$50 on Fable 5.1. Also on Vercel AI Gateway.

    Source · checked 10 Nov 2026
  • Boxes.dev (Launch YC)

    Cloud environment for AI coding: run unmodified Claude Code and Codex on parallel cloud machines with your full dev environment, using your existing subscriptions. Start agents from a desktop app, phone, Slack or Linear; each agent gets its own machine to test its work.

    Source · checked 10 Nov 2026
  • Codenotary AgentMon Live (open source)

    Free Apache-2.0 plugin for Claude Code (2.1.308+) with a live dashboard of agent and subagent activity, token and cost visibility, and a 'Done Gate' that checks for failed tests or unfinished tasks before the agent says it's done.

    Source · checked 10 Nov 2026
