This week

What shipped this week

New releases from the AI tools builders actually use, newest first. Week 46, 2026. We only list something once we've seen it on the company's own page.

Follow along in your reader with the RSS feed. An email version is on the way.

Thu 12 Nov

  • Gemini 4 Hydrogen in Cursor

    Google's Gemini 4 Hydrogen, the successor to Gemini 3.8 Flash, is now available in Cursor for everyday agentic coding. Cursor says that at its default effort it scores 54.3% on CursorBench, up from 39.6% for Gemini 3.8 Flash. It supports low, medium, high (default) and xhigh effort. It's a third-party model, so it isn't part of the usage included with Cursor plans.

    Source · checked 13 Nov 2026
  • Claude Code 2.1.323: Code Mode (experimental)

    Claude Code 2.1.323 adds Code Mode, an experimental opt-in in which Claude writes JavaScript to call its tools rather than invoking them one at a time. Organisations can turn it off. The release also lets plugins declare a supported Claude Code version range, and adds a menu when a model needs usage credits that are off or used up.

    Source · checked 13 Nov 2026
  • Replit Agent can buy supplies and run Google Ads

    Replit Agent can now buy supplies for your business and help you run Google Ads, without leaving Replit. Purchases use Link (by Stripe) and Visa: Agent prepares the checkout and waits for you to approve the total before anything is charged. Agentic Commerce is for Core and Pro users, starting in the US and limited to one-time purchases. For ads, Agent can draft copy, images and a budget across Google Search, YouTube, Display and Discover, and you approve before it launches.

    Source · checked 13 Nov 2026
  • Claude Meetings (beta)

    Anthropic is rolling out Claude Meetings in beta on Team and Enterprise plans. You can add Claude to a Google Meet call as a visible participant that takes notes, answers questions, and builds docs, whiteboards and other artifacts during the call. Support for other video platforms is coming later. During the beta, notes and transcripts are free; artifacts Claude makes on the call are free through 10 February 2027.

    Source · checked 13 Nov 2026
  • v0: Meta's Astryx design system

    Meta's Astryx design system is now available in v0. You can select it for a project and v0 builds with Astryx's components, patterns and templates in context.

    Source · checked 13 Nov 2026

Wed 11 Nov

  • Lovable Automations

    Automations let Lovable take care of recurring work, such as a morning check of your published sites, a weekly summary of new signups, or a Friday list of the oldest items in your backlog. Ask for one in Chats and say how often, and Lovable posts what it finds there. Available on Free, Pro and Business plans, and each run is chat usage.

    Source · checked 13 Nov 2026
  • Qwen Code 1.0 Preview

    Alibaba's Qwen team released a v1.0.0-preview of Qwen Code that merges the agent capabilities of its Qoder coding tool and the open-source Qwen Code CLI into one agent for understanding, implementing, debugging and testing code. You can sign in with a Qwen or Qoder account, and it ships native installers for macOS, Linux and Windows that don't need a separate Node.js install. Marked as a preview, so interfaces and behaviour may change.

    Source · checked 13 Nov 2026
  • Gemini 4 Hydrogen in Devin

    Gemini 4 Hydrogen is now live in Devin Desktop and Devin CLI. On Cognition's FrontierCode 2.0 benchmark, it scores 38.2%, close to GPT-6.1 Sol's 39.0% and Gemini 4 Carbon's 40.0%, at $2.40 per task compared with Carbon's $4.04.

    Source · checked 13 Nov 2026

Tue 10 Nov

  • Cursor Projects goes multiplayer (beta)

    Cursor Projects, where one coordinator directs a fleet of agents on large pieces of work, now lets you invite teammates into a Project to plan, build and ship together. A shared task board shows who's doing what, what each person's agents are working on and the PR behind each task. Rolling out in beta to all Cursor users.

    Source · checked 11 Nov 2026
  • Gemini 4 Carbon in GitHub Copilot (GA)

    Google's Gemini 4 Carbon, aimed at complex coding, agentic work and secure code generation, is generally available in GitHub Copilot for Pro+, Max, Business and Enterprise users, billed at provider list pricing. Pick it in VS Code, Visual Studio, Copilot CLI, the coding agent, JetBrains, Xcode and more; rollout is gradual.

    Source · checked 11 Nov 2026
  • v0 Security Review

    Ask v0 to "run a security review" and it checks the code your chat changed (or your riskiest code) for missing auth checks, injection and SSRF, verifies each finding against the whole project, and reports a severity and suggested fix. It only changes code if you agree. Paid plans; uses v0 credits.

    Source · checked 11 Nov 2026
  • Copilot in Visual Studio gets a new engine

    Visual Studio 2026 version 18.12 runs Copilot Chat on the Microsoft Copilot SDK, the same engine as Copilot CLI, the Copilot app and VS Code. You can steer it mid-task, see each step's results and per-request cost, watch subagents live and point it at folders outside your solution. On by default.

    Source · checked 11 Nov 2026
  • Runpod for Agents

    Runpod expanded its tools for letting coding agents handle GPU infrastructure: a hosted MCP server plus tested skills so Claude Code, Codex or Cursor can pick hardware, deploy Pods or Serverless endpoints, debug failures and shut things down. Destructive actions need your confirmation; native plugins for Claude Code, Codex and ChatGPT. Set up at agents.runpod.io.

    Source · checked 11 Nov 2026

Mon 9 Nov

  • Claude Fable 5.2

    Anthropic's newest Fable model, now the default Fable model in Claude Code (2.1.321) and generally available in GitHub Copilot for Pro+, Max, Business and Enterprise users. 1M context; API price $8/$40 per 1M input/output tokens, down from $10/$50 on Fable 5.1. Also on Vercel AI Gateway.

    Source · checked 10 Nov 2026
  • Boxes.dev (Launch YC)

    Cloud environment for AI coding: run unmodified Claude Code and Codex on parallel cloud machines with your full dev environment, using your existing subscriptions. Start agents from a desktop app, phone, Slack or Linear; each agent gets its own machine to test its work.

    Source · checked 10 Nov 2026
  • Codenotary AgentMon Live (open source)

    Free Apache-2.0 plugin for Claude Code (2.1.308+) with a live dashboard of agent and subagent activity, token and cost visibility, and a 'Done Gate' that checks for failed tests or unfinished tasks before the agent says it's done.

    Source · checked 10 Nov 2026
