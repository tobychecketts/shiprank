This week

What shipped this week

New releases from the AI tools builders actually use, newest first. Week 47, 2026. We only list something once we've seen it on the company's own page.

Follow along in your reader with the RSS feed. An email version is on the way.

Fri 20 Nov

  • Lovable: free domain for a year when you upgrade

    After a workspace upgrades from Free to a paid plan on the web, admins and owners can claim one domain free for the first year (claim within 90 days of first payment). Covers extensions such as .app and .dev but not .com, and renews automatically after year one.

    Source · checked 21 Nov 2026
  • Vercel Functions accept request bodies up to 20MiB (public beta)

    Vercel Functions now take request bodies up to 20MiB in public beta, up from 4.5MB, for larger uploads, webhooks and API payloads.

    Source · checked 21 Nov 2026
  • Claude Code 2.1.330: easel charts and Enterprise Admin Console sign-in

    Adds easel, a built-in mod that draws charts when asked and under MCP metrics results (Pro, Max and, where available, Team and Enterprise on macOS and Linux; switch off in /config), sign-in to organisations managed in Anthropic's Enterprise Admin Console, and fixes freezes after compacting very long conversations and in WebFetch.

    Source · checked 21 Nov 2026
  • Lovable: GPT-6.2 Astra and Sol for app AI features, plus Paystack and Square connectors

    Apps built in Lovable can now use OpenAI's GPT-6.2 Astra (complex reasoning, coding, research, at lower cost than GPT-6 Astra) and GPT-6.2 Sol (everyday reasoning and coding). New app and chat connectors: Paystack for card, bank transfer and mobile money payments in several African countries, and Square for payment links, card charges, refunds and orders.

    Source · checked 22 Nov 2026
  • OpenAI Codex CLI 0.171: GPT-6.2 Sol by default and TUI workspace

    Adds GPT-6.2 Sol and Astra to the model catalog with Sol as the default selection, turns on the TUI workspace by default (searchable document and image previews and subagent transcripts beside the chat), adds undo and redo in the prompt composer, and codex exec --remote for sessions on an existing app server.

    Source · checked 22 Nov 2026
  • DreamCoder: coding harness and IDE from the author of Mastering Emacs

    Mickey Petersen released DreamCoder, a coding harness with a tiling window manager that runs in your browser on Windows, Mac and Linux. It has background sub-agents, MCP servers, your own agents and terminals beside chats.

    Source · checked 22 Nov 2026

Thu 19 Nov

  • Lovable keeps working while you answer its questions

    When Lovable asks you a question it now carries on building the parts that don't depend on your answer and picks an option for the rest, reworking it if you choose differently. It still waits before hard-to-undo steps such as deleting data.

    Source · checked 21 Nov 2026
  • Vercel CLI: agents find commands with vercel help search

    Coding agents can run vercel help search and describe a task in plain language to find the right Vercel CLI command; add --with-help to also get instructions for the best match.

    Source · checked 21 Nov 2026

Wed 18 Nov

  • Gemini 4 Neon (Gemini API, Antigravity, Gemini app)

    Google's new mid-range Gemini 4 model for coding and agent work, sitting between Carbon and Hydrogen. Gemini API price is $3 per 1M input tokens and $15 per 1M output (thinking tokens included), with a 1M-token context window; not on the API free tier. Also rolling out to paid Google AI Pro and Ultra subscribers in Google Antigravity and the Gemini app.

    Source · checked 19 Nov 2026
  • Gemini 4 Neon in GitHub Copilot (GA)

    Gemini 4 Neon is generally available in GitHub Copilot for Pro+, Max, Business and Enterprise users, in the model picker across VS Code, Visual Studio, JetBrains, Xcode, Eclipse, Copilot CLI, the coding agent and github.com. Rolling out gradually.

    Source · checked 19 Nov 2026
  • Vercel Board (experimental, all plans)

    A shared message board where your agents and people coordinate tasks, with each task's discussion and results kept in one thread, channel-level permissions, and two-way sync with Slack and GitHub. Agents use it through the Vercel CLI or JavaScript SDK; install with npx skills add vercel/board.

    Source · checked 19 Nov 2026
  • Vercel one-second static deploys now take CSS, images and fonts

    Instant deployments, which put eligible static sites live in about a second with no build step, now accept CSS, images, fonts, PDFs and media alongside HTML and Markdown. Up to 100 files and 25 MB, deployed with the Vercel CLI or API; rolling out on all plans.

    Source · checked 19 Nov 2026
  • Google Stitch Loop (waitlist)

    An experimental product agent from Google Labs that connects to your GitHub repo and live metrics, suggests improvements, writes the code in a sandbox and opens a pull request for you to approve. Comes with built-in security, latency and accessibility loops. Waitlist open globally, with priority for eligible Google AI Ultra users.

    Source · checked 19 Nov 2026
  • Replit Desktop local work and Replit in Microsoft Teams (GA)

    Local access in the Replit Desktop app is generally available on Windows, Mac and Linux: pick which folders Replit can use, ask the Agent for changes and review them locally. Replit's Microsoft Teams integration and Microsoft Fabric integration are also generally available, with publishing to Azure in early access.

    Source · checked 19 Nov 2026
  • Netlify's new AI app-building experience

    Netlify unveiled a redesigned platform that brings AI app creation, collaboration and its production hosting together, so agents, non-technical builders and developers can build and run apps in one place.

    Source · checked 22 Nov 2026

Tue 17 Nov

  • GPT-6.2 Astra and GPT-6.2 Sol

    OpenAI's new frontier (Astra) and everyday (Sol) models, out in ChatGPT, Codex and the API. Astra's API price is 20% lower than GPT-6 Astra ($8 in / $40 out per 1M tokens, $0.40 cached input); Sol keeps GPT-6.1 Sol's prices. OpenAI says Astra builds better-looking frontends.

    Source · checked 18 Nov 2026
  • MAI Code 2 and MAI Code 2 Flash in GitHub Copilot

    Microsoft's new coding models: MAI Code 2 for multi-file work, debugging and refactors (Copilot Pro and up) and the cheaper MAI Code 2 Flash for quick edits and fixes, which is available on Copilot Free too. Billed under Copilot's usage-based billing.

    Source · checked 18 Nov 2026
  • Replit Missions

    Set an outcome and a budget and Replit runs a swarm of agents to plan, build, test and iterate towards it, with an independent AI judge checking results against your success criteria. Work stops if the budget runs out; you choose how often it sends updates.

    Source · checked 18 Nov 2026
  • Google AI Studio builds full-stack Android apps

    AI Studio's Build agent can now go from a prompt to a Kotlin Android app with a Firestore database, Google Sign-In and Gemini API calls that keep your key out of the APK, then publish it to your own Google Play library. Also adds a faster HD emulator and one-click screenshots to the agent.

    Source · checked 18 Nov 2026
  • Claude Code 2.1.327: add MCP servers from stdin + /status health list

    claude mcp add-json <name> - reads the server's JSON from stdin so API tokens stay off the command line, /status now lists broken agent, skill and command files, and /export asks before overwriting a file. Also fixes project-scope mcp add/remove wiping other keys in .mcp.json.

    Source · checked 18 Nov 2026

Mon 16 Nov

  • ngrok MCP server (all plans, including free)

    ngrok's MCP server is live at mcp.ngrok.com/mcp. Your coding agent can list and explain endpoints, query traffic from Traffic Inspector, write and validate Traffic Policy rules, report usage and search the current ngrok docs. Works on every ngrok plan, including free.

    Source · checked 17 Nov 2026
  • Vercel Spend Management: project and product budgets

    Set a budget for a single project (optionally pausing just its production deployments when it's reached) or for one product such as Fast Data Transfer, alongside team budgets. Alerts at 50%, 75% and 100%; also manageable with vercel billing budgets in the CLI. No extra cost for Pro teams.

    Source · checked 17 Nov 2026
  • Lovable: test database changes in a draft

    On projects using Lovable's built-in backend, a draft now gets its own backend filled with example data, so you can test a change that stores new information without touching your live app. Accepting the draft applies the change to the live database and leaves the test data behind. Chats can also now be archived.

    Source · checked 17 Nov 2026
  • TeamCity AI Agents plugin: Codex and Claude Code in CI (experimental)

    JetBrains' experimental plugin installs Codex or Claude Code on a TeamCity build agent, hands over provider credentials only for the build, and records token counts and the agent's full trajectory as HTML/JSON. Connects to OpenAI, Anthropic, OpenRouter, LiteLLM or JetBrains Air.

    Source · checked 17 Nov 2026
