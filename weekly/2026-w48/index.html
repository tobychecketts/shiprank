This week / Week 48, 2026

What shipped in week 48

13 releases for people building with AI. We only list something once we've seen it on the company's own page.

Wed 25 Nov

  • Claude Code 2.1.332: skills from MCP servers (beta) and a PreSkillShellCommand hook

    MCP servers can now ship skills, which show as server:skill in the / menu (beta). A new PreSkillShellCommand hook can refuse a skill's inline shell commands as it loads, and a long list of fixes targets freezes from flooding hooks and MCP servers, compaction failures and SSE MCP servers that hung after a dropped stream.

    Source · checked 25 Nov 2026

Tue 24 Nov

  • Devin: Cognition's SWE-2.1 model, plus a 10x-faster Ultrafast version

    Cognition's new in-house coding model is trained with reinforcement learning on Kimi K3 and roughly doubles SWE-2's scores on Terminal-Bench 4.1 (50.0 vs 24.2) and FrontierCode 2.0 (41.3 vs 24.1). SWE-2.1 Ultrafast runs the same model at 10x the speed through a Cerebras partnership, and a more permissive SWE-2.1 Cyber version powers Devin Security scans.

    Source · checked 25 Nov 2026
  • GitHub Copilot CLI 1.0.115: Gemini 4 Hydrogen, GPT-6.2 Astra and custom provider models

    The model picker adds Gemini 4 Hydrogen (with Extra High reasoning where available), GPT-6.2 Astra and MAI-Code-2-Flash, and you can add and manage your own provider models from /model. Windows sandbox package queries are now on by default, and timeline items can show timestamps.

    Source · checked 25 Nov 2026
  • Google Antigravity adds MCP Apps

    MCP tools can now render interactive HTML views in Antigravity instead of raw JSON: inline in chat, as a side-panel tab, as a full page in the sidebar, or as a custom viewer for a file type. Standard MCP Apps work without code changes; launch plugins include Vercel, Datadog, CodeRabbit, Better Stack, monday.com and Qodo.

    Source · checked 25 Nov 2026
  • Vercel: agents can manage AI Gateway through Vercel MCP

    Ask your coding agent in plain language to create reusable virtual model IDs, set team-wide routing rules that redirect or block requests, and set spending budgets for your team, projects and members. Apps then call the virtual model ID, so you can swap the model behind it without redeploying.

    Source · checked 25 Nov 2026
  • OpenAI Codex CLI 0.172: thread links, slash-command Tab completion and Bedrock sign-in

    Follow thread links from search results and transcripts to reopen saved conversations and nested agents, press Tab to complete slash-command arguments, and jump between task groups in the agent command center. App-server clients can pick Amazon Bedrock Runtime at setup, and codex exec resume now restores saved sandbox permissions and workspace roots.

    Source · checked 24 Nov 2026

Mon 23 Nov

  • Lovable: publish to Databricks, auto test users and redesigned security checks

    Projects linked to Databricks can now publish as a Databricks App from the publish dialog. When testing pages that need a signed-in user, Lovable can create (and later remove) a test user with your approval. The Security view now shows checks first, and running checks doesn't use credits. Also new: Asaas payments for Brazil and a Paper design connector.

    Source · checked 25 Nov 2026
  • Gemini API file slicing controls

    Pass PDFs, Office and OpenDocument files, audio and video to the Gemini API and ask for only the pages, sheet and cell ranges, or time segments you need; you're billed tokens only for the parts Gemini inspects. Works across all Gemini 4 models in Google AI Studio and the Gemini platform.

    Source · checked 25 Nov 2026
  • Supabase Knowledge Base (supabase.com/kb)

    A new open-source home for migration guides (from Firebase, Auth0, Neon, Heroku, Vercel Postgres and more), hundreds of troubleshooting articles, FAQs, tutorials and community guides. Every page has a Markdown version that coding agents can request, and it's wired into Supabase's llms.txt.

    Source · checked 25 Nov 2026
  • Claude Ship (beta): Claude reviews, fixes and approves pull requests

    Anthropic's new PR workflow pairs Code Review (GA) with two beta agents: PR Steward keeps a pull request green by fixing failing CI, merge conflicts and review feedback, and Claude Approvals approves routine changes under a policy file in the repo. Developers can run the new /ship command in Claude Code. Available on Claude Team and Enterprise for GitHub repos, billed on tokens.

    Source · checked 24 Nov 2026
  • Claude Code 2.1.331: Code Mode on Bedrock and Foundry, API check in claude doctor

    Code Mode now works in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and Claude Platform on AWS. claude doctor gains an API connectivity section, plugins can list optional dependencies, and fixes cover MCP tool calls that hung for up to 30 minutes and /compact losing part of its summary.

    Source · checked 24 Nov 2026
  • GLM-5.4: Z.ai's coding model built on a Loop Transformer

    Z.ai's new flagship loops 28 layers of its 750B GLM-5 base twice for deeper reasoning, adds vision, and targets "Generalized Coding" such as games, 3D and CAD work. Available now in the GLM Coding Plan, ZCode and Z.ai Chat; API access is listed as coming soon and open weights are promised after safety hardening.

    Source · checked 24 Nov 2026
  • Vercel Drives get CLI commands and standalone SDKs

    Create, list, fork and delete Vercel Drives with new vercel drives CLI commands, the @vercel/drives TypeScript SDK, the vercel-drives Python SDK or a /v1/drives REST API, without needing Sandbox APIs. Drives still mount into Vercel Sandboxes and are available on Hobby, Pro and Enterprise.

    Source · checked 24 Nov 2026
