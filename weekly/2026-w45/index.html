AI launches: week 45, 2026

11 launches, each confirmed on its source page.

Friday 6 November 2026

Cursor: voice chat with agents

Talk to Cursor agents in a realtime voice call from the Agents Window, IDE, web or Cursor for iOS. The voice agent hands coding work to the chat agent and gives spoken progress updates; runs on Grok Voice, with zero data retention in Privacy Mode.

Source ↗ · verified 2026-11-08

@GitHub in Slack and Teams (GA)

Mention @GitHub in Slack or Teams to investigate bugs, create issues, implement changes and open pull requests from a conversation. Adds Canvas in Teams for reviewing plans, diffs and previews, plus automatic repo detection.

Source ↗ · verified 2026-11-08

OpenAI Codex CLI 0.167: agent command center

OpenAI's Codex CLI rust-v0.167.0 adds codex agents --no-daemon for an agent command center with unread markers, lets you switch backends from the session picker without losing drafts, and adds local image previews plus a Google Cloud Vertex AI setup path.

Source ↗ · verified 2026-11-07

Claude Code 2.1.319: background MCP tasks + deny-instead-of-prompting

Anthropic's Claude Code 2.1.319 backgrounds MCP tool calls that run as tasks, adds permissions.denyInsteadOfPrompting so a blocked tool call fails closed instead of waiting, and ships /claude-api latency-optimize plus CLAUDE_CODE_DISABLE_FEATURE_FLAGS. It also hardens auto mode behind LLM gateways and fixes sandbox-escape and Bash permission-bypass bugs.

Source ↗ · verified 2026-11-07

Thursday 5 November 2026

Hermes Agent v0.23.0: full Desktop workspace in a browser

NousResearch's open-source Hermes Agent can now serve its full Desktop workspace in a browser tab from your own gateway (off by default). One gateway owns every session, and the release adds /rewind, pluggable delegation, plugin auto-updates and spend limits for paid MCP tools. Check the breaking changes before upgrading.

Source ↗ · verified 2026-11-09

Cursor: Build Live Apps from cloud agents

Cursor cloud agents can scaffold a web app, spin up Postgres when needed, configure Cursor SSO auth, run publish-time security checks, and return a live shareable link. Available on paid plans with cloud agents enabled; local agents cannot publish.

Source ↗ · verified 2026-11-07

Wednesday 4 November 2026

Perplexity Teammates (research preview)

Always-on agents built on Perplexity Computer that own ongoing work: they plan tasks, coordinate other agents, watch connected tools like Slack, GitHub and Linear, and follow up on things like PR review comments. Research preview on the web for individual Perplexity Max subscribers.

Source ↗ · verified 2026-11-09

GitHub Copilot in Xcode's coding assistant (public preview)

GitHub Copilot is now available inside Xcode's built-in coding assistant as a public preview starting with Xcode 27.3 beta on macOS Tahoe 26.6+. The existing Copilot for Xcode extension remains a separate option; all Copilot plans are supported.

Source ↗ · verified 2026-11-07

Claude Code 2.1.318: cloud sessions without a repo + sign-in expiry warnings

Anthropic's Claude Code 2.1.318 lets a cloud session on an Anthropic-hosted environment start with no repository picked, shows when a stored claude.ai sign-in ends (in claude auth status and claude -p JSON, plus a warning 10 days before), and adds an effort option for quick side jobs. It also fixes lost --continue history, macOS stalls with many Bash commands, and config and login corruption on shared network home directories.

Source ↗ · verified 2026-11-04

Tuesday 3 November 2026

Vercel Security Review (public beta)

Vercel Security Review is in public beta for Pro and Enterprise teams. Once enabled, every push to a connected GitHub repo is reviewed for vulnerabilities, with findings (summary, suggested fix and AI-rated severity) in a Vulnerabilities dashboard, a GitHub check and PR comments. Fix with Vercel Agent opens a PR, or pull findings into your own coding agent with vercel security vulnerabilities. Reviews are free until 10 November 2026, then billed at the Vercel Agent rate.

Source ↗ · verified 2026-11-04

GitHub Copilot in JetBrains Air

GitHub Copilot is now available as an agent in JetBrains Air through the Agent Client Protocol. Pick Copilot in Air's agent picker to delegate coding tasks on your existing Copilot subscription, track several agent sessions in parallel and review changes next to your code. Cloud tasks run in isolated containers through Air Teams and use your Copilot plan rather than JetBrains AI credits.

Source ↗ · verified 2026-11-04
